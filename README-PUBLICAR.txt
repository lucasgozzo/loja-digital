LOJA DIGITAL - PUBLICAÇÃO GRÁTIS NO GITHUB PAGES

1. Crie/entre na sua conta em github.com.
2. Crie um repositório público chamado: loja-digital
3. Antes de enviar os arquivos, abra index.html no Bloco de Notas e procure:
   const BOT_USERNAME = "SEU_BOT_AQUI";
   Troque SEU_BOT_AQUI pelo username do bot SEM @.
4. Envie para a raiz do repositório:
   index.html
   privacidade.html
   termos.html
   pasta assets
5. No GitHub: Settings > Pages.
6. Em Build and deployment > Source escolha "Deploy from a branch".
7. Branch: main / (root) > Save.
8. O endereço ficará parecido com:
   https://SEUUSUARIO.github.io/loja-digital/
9. Abra a URL e teste. Essa é a URL que você pode informar como site do negócio, desde que represente corretamente sua operação.

IMPORTANTE:
- Não envie .env, tokens, chaves, store.db ou qualquer segredo para o GitHub.
- O site é apenas a página pública. O bot continua separado.
